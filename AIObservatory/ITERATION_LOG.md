# Prompt Categorization Iteration Log

This document tracks the systematic refinement of the Unsupervised Machine Learning (TF-IDF + K-Means) pipeline used for categorizing prompts. It documents the roadblocks encountered, the architectural pivots, and the back-to-back iterative changes made to optimize the model's accuracy.

## Challenge Overview
The pipeline initially struggled with severe miscategorization and an enormous "Other/Miscellaneous" bucket. The root causes were identified as:
1. **Taxonomy Ambiguity**: Overlapping keywords in the original LLM-generated taxonomy caused prompts to match multiple categories simultaneously.
2. **TF-IDF Greediness**: Generic corporate action verbs (e.g., "optimize", "analyze", "strategy") hijacked thousands of prompts, pulling them into incorrect categories simply because they shared a common verb, stripping away the actual intent.
3. **Conversational Fluff**: Users interact with AI using conversational filler (e.g., "can you tell me", "I have a question about"), which the algorithm misinterpreted as meaningful keywords, grouping unrelated prompts together based on politeness rather than technical substance.

---
*Note on Semantic Search*: During Round 4, a major architectural limitation was discussed. TF-IDF acts as a lexical keyword-matcher, not a true semantic engine. Aggressively filtering action verbs (e.g., "optimize") reduces the engine to noun-based topic modeling (losing the intent of *what* the user is doing to the noun). To combat this without switching to a slow, deep-learning Local Embedding model, the pipeline relies on Bi-Grams (`ngram_range=(1, 2)`) to capture multi-word intent (e.g., "optimize code") while filtering out the standalone verb.
